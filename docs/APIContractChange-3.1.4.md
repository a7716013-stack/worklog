# API Phase D — 3.1.4

Application owns source, acquisition and dataset projections. Controllers only query, page and map HTTP errors. Existing `/api/v1` contracts retained.

| Resource | Change |
|---|---|
| GET /authority/sources | New paginated source/version catalog, capability and access metadata |
| GET /authority/acquisition-plan | New paginated tasks; optional exact compound `claimKey`, next action included |
| GET /authority/acquisition-attempts/{id} | New; `id` is the deterministic acquisition TaskId, returns its sanitized attempt history |
| GET /research/components/{component}/readiness | New independent component build projection |
| GET /research/datasets/{id}/readiness | Additive `builds`, `buildReportDigest`; retains all 3.1.3 fields |
| Existing closure-queue, claims/{id}/evidence, validation-summary, replay-status, PIT/coverage | Reused unchanged |

The candidate next-actions and build-readiness routes are not duplicated: actions live on plan tasks; build reports extend dataset readiness. Components use exact existing names (Trend, Momentum, VolumePrice, Institutional, RelativeStrength, RiskQuality). Compound claim keys include the domain; ambiguous plain claim IDs remain rejected by the existing evidence API.

Authority endpoints use ApiAuthorityRead; research endpoints use ApiResearchRead. Existing session, ReadPolicy, ProblemDetails and X-Trace-Id apply. Unknown resource 404, invalid filter/page 400, missing/inconsistent report 503 DATA_NOT_READY. No public acquisition, approval, promotion or trading mutation. Shared published research metadata is nonpersonal; existing personal-resource isolation is unchanged. Paths, operator identities, archive locations and raw failure exception text are excluded from attempts.

Capabilities use string states VERIFIED/PARTIAL/UNKNOWN/UNSUPPORTED; this export's historical publication/revision capabilities remain UNKNOWN. Captured content version is a SHA-256 identity, never proof of historical revision semantics. `SupportedClaims` contains only historically established claims (empty here); `CandidateClaims` lists research requirements associated with that source. `TemporalCoverage` remains UNKNOWN_HISTORICAL_APPLICABILITY. License UNKNOWN_REUSE_RIGHTS is not a permission grant. Product/archive access that may need purchase/login/contact is MANUAL_ACTION_REQUIRED.

Dates use ISO calendar dates and timestamps carry UTC offsets. Unbuilt independent component counts, snapshot, eligibility digest and approval are null; `ApprovedResearchSamples=0` explicitly means none approved. Facts and research observations have separate denominators. Missing metrics remain null. Replay means verified at export, not a live connection to offline evidence stores. A source invalidation marks builds REEVALUATION_REQUIRED and blocks controlled baseline execution; publish a newly verified report after offline changes.

Acquisition limits: 3 attempts per task, 20 per provider/hour, one executor at a time across processes sharing the store, 16 MiB response limit, 30-second overall attempt deadline, 10-second connect deadline. Only registered archived official HTTPS URLs, port 443, no credentials/fragments; redirects/proxies/cookies disabled; resolved private/reserved DNS destinations rejected and checked address pinned for connection. HTTP 404/410 means source unavailable, not proof data never existed. 401/403 is manual action; 429 is quota and not automatically retried. Transient failures/timeouts allow bounded retries. Interrupted reservations still consume budget.

OpenAPI snapshot is regenerated by ApiContractChecks; prior contract compatibility plus new authentication, paging, null semantics and safety checks run in the existing same-SHA CI.
