# Authorization implementation — 3.2.1

Feature.SwingAnalysis and Feature.PaperPortfolio require the existing authenticated Identity principal and NameIdentifier. FeatureAccess metadata selects HTML redirect versus JSON 401/403. AnalysisAccess protects only analyze=true, retaining public quotes. MemberCacheFilter applies no-store/private to protected MVC output; APIs retain no-store and stable trace headers. Cookies remain Secure/HttpOnly, Google login remains PKCE/state/correlation checked, and return URLs remain local. No new login system, owner input, schema or production migration.

PaperTradingService derives ownership from ICurrentUser; account/order/position/trade/cancel/refresh/reset queries constrain owned account IDs. Reset also validates generation and executes under the existing transaction/app lock. API DTOs omit applicationUserId/accountId. Portfolio history uses server owner; system portfolio capture receives explicit account IDs, not a borrowed ambient principal. Strategy signals are shared system scan results, not user-owned objects; member access and order symbol binding remain required. Recommendations use AccessibleAsync/ValidateAsync and personal owner rules; ordinary membership never implies authority approval/admin access.

Radar background jobs process shared market snapshots only. They hold no member principal and expose status only to members. Personal writes stay within scoped services and explicit owner context. Old shared/unassigned paper data is preserved and excluded from member queries. Navigation keeps Swing/Paper visible with login hint. Swing/paper/market fetch handles expired sessions; protected pages reload on bfcache restore. The market page displays basic quotes anonymously and does not trigger the analysis job until logged in.

Remaining legacy EF service/hosting references stay in Web because moving them without their transaction/Identity dependencies would expand the release unnecessarily. New ETL orchestration and ICurrentUser contract are in Application. This is an incremental extraction, not a claim that all legacy business code has moved.
