# Worklog 1.2.3：市場熱門排行

## 入口與資料

本機入口 `https://localhost:7180/StockAnalysis/MarketRadar`，正式入口 `https://worklog.ork-ournal.workers.dev/StockAnalysis/MarketRadar`。公開讀取市場資料；寫入個人自選或進入虛擬交易須登入。部署沿用既有 GitHub main、Azure App Service 與 Cloudflare 入口。

主要行情為 TWSE `exchangeReport/MI_INDEX?response=json&type=ALLBUT0999` 及 TPEx `tpex_mainboard_daily_close_quotes`；上市備援為 TWSE OpenAPI `exchangeReport/STOCK_DAY_ALL`。用 FinMind `TaiwanStockInfo` 對照上市、上櫃與 ETF 分類，不將權證混入排行。成交量一律以原始「股」計算，畫面依大小顯示股／萬股／億股。價格漲跌幅由官方漲跌價差及收盤推算，特殊無法解讀的除權息差額留空。

官方來源：https://openapi.twse.com.tw/ 、https://www.tpex.org.tw/openapi/ 。候選歷史來源：https://finmind.github.io/tutor/TaiwanMarket/Technical/ 。市場來源日期不同時不混排，只顯示所選日期並提示缺少市場。休市或資料未更新時顯示最近來源交易日。

重大資訊讀取 TWSE `opendata/t187ap04_L` 與 TPEx `mopsfin_t187ap04_O`，包含主旨、時間、公司、來源及說明。僅代表來源提供的公告範圍，不保證完整七日新聞覆蓋，空結果不可解釋為沒有風險。外部內容以文字呈現，網址只允許 HTTP(S)。

## 公式

- 當日三榜各取 20 檔：正漲幅降序、負漲幅升序、成交股數降序；交集去重，最多 60 檔進階分析。
- 前 5／20 個有效交易日均量不含當日。量比＝當日量÷均量；量增＝（量比−1）×100%。樣本不足、缺量或均量為零，量比留空。均量排序只在候選池內，異常放量門檻 20 日量比 ≥1.5。
- 價格動能 20：漲幅 ≥7/5/3/1/0/-3% 對應 20/18/15/10/6/2 分，其餘 0。
- 成交量異常 20：20 日量比 ≥5/3/2/1.5/1 對應 20/17/14/10/6 分，其餘 2；下跌日上限 5 分。
- 技術面 20：收盤>MA20 +5、MA5>MA20 +3、MA20>MA60 +3、收盤>MA60 +2、MACD 柱>0 +4、RSI 50～70 +3。沿用既有 `TechnicalIndicators`；黃金交叉需與前一日訊號比較，不把一直處於多頭區間稱為剛交叉。
- 籌碼面 15：同一交易日外資買超 +10、投信買超 +5；缺任一項則不可評分。
- 基本面 10：最近可用營收月份須在前兩個月內；營收年增 ≥20/10/0% 為 10/8/5 分，負成長 0。ETF 不適用公司營收，基金基本面列未提供。
- 重大資訊 15：近 7 日來源可確認的營收／法說公告 15 分、其他公告 10 分；表示研究關注度，影響方向保持 Unknown。沒有可確認資料時不可評分。

所有分項可展開查閱。全部六項可評才顯示 `分數 / 100`，否則顯示已知分數與可評權重，不正規化。候選依已知分數、可評權重、代號排序；缺項的股票可能因資訊較少而排序較後，不能將此解讀為投資品質評比。等級是追蹤優先級；風險標籤獨立顯示過熱、超跌、大跌、爆量、量價背離、事件待確認及資料不足。

## 快取、負載與錯誤

每次市場快照最多 5 個上游請求（兩個行情、兩個公告、一個可快取目錄），上市備援再加 1。行情／公告快取 5 分鐘，失敗快取 1 分鐘，商品目錄沿用既有 12 小時快取。

最多 60 檔候選，每檔歷史價格及法人各 1 次，非 ETF 月營收再 1 次，上限 180 次候選請求；不是全市場逐檔掃描。跨請求最多 4 檔併發，批次鎖防止同時開頁重複拉取。歷史快取 15 分鐘，無價格／法人或服務錯誤 1 分鐘；key 含資料源、資料類型、交易日與代號。重新整理沿用有效快取，仍受 FinMind 帳戶額度限制。

頁面先顯示當日排行，再載入較慢的候選分析；切換篩選會取消舊請求。取消向下傳遞至 HTTP；單檔資料失敗保留官方行情與其他候選結果，不顯示原始上游錯誤、Token 或堆疊。公用快取不包含個人自選狀態；個人狀態使用現有授權 API 載入。

## 驗證與限制

測試涵蓋六項權重、分數界限、5／20 日均量、排除當日／未來資料、資料不足、ETF 不套公司基本面、負量價風險、排序／去重、日期隔離、快取、錯誤降級與取消。

瀏覽器使用隔離 SQL 及明確固定行情，驗證自選持久化、防偽、虛擬單帶入、事件 XSS／網址過濾、市場／日期切換與手機排版。真實市場另以本機唯讀 API 驗證，不將測試資料用於產品。

已知限制：未還原價格受企業行動影響；公開公告並非完整新聞源；ETF 基金基本面尚未評分；量比排行只覆蓋候選池。後續可擴充具公告時間的完整事件資料、ETF 淨值／追蹤差異及經授權的全市場歷史整批資料。
