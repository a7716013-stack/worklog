# WorkJournal 1.3.1 — 首頁介面整合

日期：2026-10-08。基準 GitHub main：468463fb2808b88a8bde0e375eae7f76a15d6786。
本版發布至 GitHub main 與既有 Azure 正式站；不啟用 Always On 或變更付費方案。無資料庫 schema 變更／migration。

## 實作

首頁 / 與 /Home/Index 改為工作＋投資儀表板：三張摘要卡、今日工作與行程、市場四張指標卡、已保存的 Radar TOP 5、推薦產業分布與個人投資入口。資料缺失顯示空狀態或不可用狀態，沒有虛構指數、分數或損益。

新增 HomeDashboardViewModel，各摘要允許 null。HomeController 僅協調讀取與呈現；新增 HomeDashboardService 只做既有 model 的唯讀查詢與彙整，不實作另一套工作、交易或同步規則。

## 資料來源

| 區塊 | 來源與行為 |
| --- | --- |
| 日期 | UTC 轉台北 UTC+8 |
| 今日工作 | WorkLogs，依登入者 ApplicationUserId 與今日日期篩選；數量／完成數，最多 5 筆，未完成優先 |
| 今日行程 | CalendarAggregationService，沿用本地工作與 Google 事件的合併／去重；只列今日交集，最多 5 筆；來源不完整不冒稱總數 |
| 市場狀態 | IMarketRadarService.GetAsync(all, null, false)，沿用 provider cache；顯示來源行情日及標的數，不推測交易所即時開閉狀態 |
| Radar TOP 5 | 最新 MarketRadarDailySelections 按 Rank 取 5 筆，沿用推薦快照 Score 及既有 MarketRadarStock.Level；不呼叫分析或重新評分 |
| 產業熱度 | 上述每日推薦中可靠的已保存 Industry；排除未知與 ETF，明示為推薦樣本分布，非全市場成交熱度 |
| 自選／個人追蹤 | StockWatchlistItems、未停止的 MarketRadarPersonalTrackings，依登入者篩選 |
| 虛擬交易 | 先以登入者篩選 PaperTradingAccounts，再計算其正持倉筆數及 Pending 委託數；不建立帳戶、不更新行情、不成交 |
| 權益／損益 | 不在首頁計算；入口導向既有 PaperTrading，避免 GetPortfolioAsync 建帳戶與逐檔查價的副作用 |

每日推薦沒有保存時顯示空狀態，不以私人手動追蹤資料補入公共區塊。休眠或休市可能使推薦日期不是今天，介面會顯示實際保存日期。

## Navigation / Responsive

- Desktop：首頁、工作管理、股票研究、我的投資；右侧代號搜尋及帳戶選單。
- 行事曆入口為既有 /WorkLogs#calendar，另保留 Google 授權管理入口。
- 自選清單使用既有 /StockAnalysis/Swing#watchlist-heading，沒有把 JSON API 當作頁面。
- 保留 Google 登入、POST 登出與 antiforgery partial；Bootstrap dropdown / collapse 支援鍵盤、aria-expanded、aria-current、跳至內容連結。
- / 預設由 WorkLogs 改為 Home；/WorkLogs 及其所有既有 actions 保留。Google 登入後既有預設導向不變。
- 桌面 12 欄、平板 2 欄、手機 1 欄。卡片、留白、字級、按鈕、徽章、空狀態及載入樣式集中在 dashboard.css。
- 沿用 Bootstrap，未新增前端框架或套件。
- 瀏覽器驗證 320、390、768、1024、1440 寬度；無水平溢出，手機選單不超出畫面，桌面鍵盤可開關與移動下拉選單。

## Security audit

- Personal Home 只以登入 claims 取得 owner；外部 userId query 不可切換帳號。
- CalendarSummary 需要登入。公共 MarketSummary 只讀每日公開推薦，排除私人手動推薦。
- 全部 Home 回應 no-store；個人資料不進公共快取。
- Razor 編碼工作標題、Google 事件與快照文字，沒有 Html.Raw 輸出外部資料。
- 測試涵蓋 A/B 的工作、自選、雷達追蹤、持倉、委託隔離及 HTML 注入。
- 首頁不執行同步、交易、帳戶建立或推薦保存；測試確認讀取後帳戶／委託數沒有改變。
- 既有 Google 登入/登出、CSRF、授權檢查與核心操作測試通過。測試 OAuth 為合成回應，不代表真實帳號重新登入驗證。

## Performance audit

- 首頁 HTML 不等待股票／Google 外部 API，市場與行事曆以兩個獨立請求載入。
- 外部來源失敗或超時只顯示對應區塊不可用，首頁仍 HTTP 200；市場故障仍可顯示已保存推薦。
- 單組讀取有 8 秒取消預算；瀏覽器 widget 有 20 秒上限。EF 同一 scoped context 的查詢依序執行，避免並行 context 錯誤。
- 重用市場 provider cache，首頁 analyze=false，沒有逐股歷史行情 API 呼叫或第二套評分邏輯。
- 個人計數使用 SQL COUNT，工作只取 5 筆；每日推薦至多既有前 10，首頁只顯示 5 筆。
- 本機單次實測：匿名首頁約 0.4 秒，市場摘要約 2.8 秒（非效能保證）。
