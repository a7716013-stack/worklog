# WorkJournal 1.4.1 — 股票整合研究與獨立自選

## 使用方式

搜尋股票代號或名称後進入 `/StockAnalysis?symbol=2330`。唯一名稱結果轉向代號，多個結果供使用者選擇。上方摘要顯示最新可用日收盤，並可加入自選、績效追蹤、波段分析或開啟虛擬委託。已加入的個人狀態提供查看入口；不會自動建立交易。

總覽以七個研究問題排序；另外七個分頁提供 K 線、技術、籌碼、基本面、事件、策略與個人績效。走勢、Radar／事件、個人狀態分開載入。來源失敗可重試，不影響已取得的區塊。分頁支援左右／Home／End，图表左右鍵與指標點選。

## 資料與判讀

- FinMind 日行情，非即時盤中價。區塊各自標示日期，不將不同日期偽裝為同步行情。
- 未還原價格，MA 為交易日簡單平均；除權息或分割影響不另作假設。至少 60 筆才能形成 MA60。
- 量比對照前 5／20 個交易日，不含當日；任一筆量缺漏則該均量為空。1.5 倍以上標示放量、0.7 倍以下縮量，只是觀察門檻。
- 法人為股數，當日／5／20 交易日按行情日期對齊。缺漏不補零；自營商只在總數或自行買賣＋避險完整時提供。
- 短期看股價與 MA20 的位置及方向，中期看 MA60；條件分歧顯示整理。前 20 日高低為參考價位。
- Radar 使用既有 V1，缺資料時显示已知得分與可評權重；不虛構完整 100 分。波段策略使用既有独立模型。
- 基本面沿用既有月營收與估值；EPS 尚未接入，因此不顯示數值。ETF 使用既有 ETF 專用資料。
- 公告顯示來源時間與安全的 HTTP(S) 來源連結；沒有資料不宣稱沒有重大消息。
- 績效顯示個人最近 20 筆推薦快照報酬、虛擬委託與已實現損益，清楚區分推薦收盤基準與個人追蹤起算。

## 資料拆分與相容性

`20261011160203_AddIndependentStockFavorites` 建立自選表並一次複製 StockWatchlistItems。舊表繼續提供波段分析，既有 Watchlist／SaveWatchlist API 語意保持不變；FavoriteItems／SaveFavorites 提供獨立自選。各清單刪除不連動，所有寫入為登入＋CSRF 保護，並以 SQL application lock 控制容量與去重。

首頁與導覽的自選入口改為 `/StockAnalysis/Favorites`；市場雷達收藏也改接自選，另保留波段按鈕。既有 PaperOrder、持倉、交易現金、不可變推薦快照與評分核心不變。

## 本機升級與驗證

先建立 COPY_ONLY／CHECKSUM SQL 備份並 RESTORE VERIFYONLY，再升級本機 WorkJournal；比對所有既有表筆數。詳細結果在 artifacts/local-migration141.json。

驗證包含 StockResearchChecks（均量、趨勢、法人缺值、名單隔離、容量及實際舊資料搬移）、既有 Radar／PaperTrading／HomeDashboard 檢查，以及 stock_research_browser_test.py。瀏覽器涵蓋搜尋、八個分頁、均線數值、區間／鍵盤、ETF、資料來源失敗、登入／CSRF、個人隔離與手機版。

本版發布至 GitHub 與 Azure，先備份正式資料庫再執行此 migration；不變更 Always On。401 項程式檢查、四組功能瀏覽器測試及本機真實行情頁面驗證通過。
