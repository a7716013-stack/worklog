# 2.0.2 — V2 Foundations

依桌面「V2 Foundations 版本2」實作 Phase 2，採現有 ASP.NET / EF Core / SQL Server 模組化單體。

- 新增永久 InstrumentIdentity、歷史代號及具有效期間的 Legacy StockId 對照。
- 新增資料快照、來源與原始 JSON 內容、歷史 Universe、Benchmark 定義／版本／對照。
- 新增不可變 VersionSet、Canonical JSON ParameterSet、可持久查詢的 DecisionTrace。
- 歷史查詢必須指定 snapshot ID 與 DataCutoff；AvailableAt 未知或晚於截止時間的資料不會進入 PIT 結果。
- 新增 SQL 交易協調、內容識別、重試與跨連線併發測試，以及同 SHA V2 CI gate。
- 兩支 additive migration，共 14 張 V2 表。既有評分計算、75 分邊界與 Golden expected values 維持原樣。

FullEvidence100 只建立 Evidence contract；本版未啟用新的正式評分、策略或自動交易。V2Threshold 與所有尚未決定的交易政策保持 UNRESOLVED。

詳細設計、測試與限制見 [實作報告](../implementation-2.0.2.md)。
