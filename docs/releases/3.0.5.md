# 3.0.5 — Phase 4 Research Infrastructure

新增 PIT 研究輸入、獨立 future-close labels、每日 IC／RankIC、分位數與分布、相關性、消融、時間切分／walk-forward、OOS 選擇鎖定、持久化與確定性重播。保留既有 Candidate 引擎、Legacy 評分與所有 CI gates，新增 `v3-research`。

本版發布研究基礎設施，不啟用正式 V3 評分、不自動晉升模型、不新增交易策略。真實 PIT 資料與 Research／OOS 驗證尚不足，完整模型 promotion 仍被資料缺口阻擋。部署不需要資料庫 migration。

完整操作、測試與缺口見 [實作報告](../implementation-3.0.5.md)。
