# 3.0.6 — Phase 4B 歷史 PIT 資料邊界

新增官方歷史來源封存、版本化可得時間政策、歷史股票池／基準／修訂隔離、確定性資料集與重播，並以既有 Candidate／ResearchEngine 執行研究。新增候選登錄、證據驗證報告與獨立 PIT CI。

本機 45 項新資料集檢查及既有完整回歸通過。官方 2330 歷史樣本已保存，但原始公布時間、歷史版本、股票池與價格政策證據不足，真實研究維持 BLOCKED_BY_DATA。測試通過不等於預測能力已驗證。

既有評分公式及正式網站流程保留；沒有資料庫 migration、模型 promotion 或交易規則變更。詳見[實作與缺口報告](../implementation-3.0.6.md)。
